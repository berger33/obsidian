# Onde buscar suporte técnico e contribuir: GitHub Discussions, Issues e `#opentofu` no Slack da CNCF

## Em uma frase
A abertura da seção Getting help and contributing no README oficial organiza os três canais de suporte e colaboração: postar dúvidas no GitHub Discussions (`https://github.com/orgs/opentofu/discussions`), abrir uma issue no GitHub (`https://github.com/opentofu/opentofu/issues/new/choose`) e participar do canal `#opentofu` no Slack da CNCF (`https://opentofu.org/slack/`), além do guia `CONTRIBUTING.md`.

## Por que importa
Separar dúvidas e debates abertos (no GitHub Discussions da organização `orgs/opentofu/discussions` e no canal `#opentofu` do Slack da CNCF) dos relatos estruturados de bug e RFCs (em `issues/new/choose`) mantém a triagem de engenharia ágil.

## Como funciona
Use `github.com/orgs/opentofu/discussions` ou o canal `#opentofu` no Slack da CNCF para tirar dúvidas de configuração e migração, e use `github.com/opentofu/opentofu/issues/new/choose` quando identificar um bug reproduzível ou quiser abrir uma solicitação formal.

## Exemplo
O atalho `https://opentofu.org/slack` no topo do README redireciona diretamente para o acesso ao canal do projeto no Slack da CNCF.

## Limites e trade-offs
Para vulnerabilidades de segurança ou questões de copyright, não utilize estes três canais públicos; siga as seções específicas de Security Policy e `liaison@opentofu.org` do mesmo README.

## Como verificar
Conferi a seção Getting help and contributing no README oficial de `opentofu/opentofu`.
