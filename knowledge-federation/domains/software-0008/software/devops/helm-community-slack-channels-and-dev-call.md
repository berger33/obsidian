# Canais oficiais no Kubernetes Slack (`#helm-users`, `#helm-dev`, `#charts`), lista de e-mail e Developer Call

## Em uma frase
A seção Community, discussion, contribution, and support do README oficial organiza os pontos de contato da comunidade em três frentes: três canais no Kubernetes Slack (`#helm-users` para usuários, `#helm-dev` para desenvolvimento do cliente e `#charts` para empacotamento de charts), a lista de discussão `cncf-helm` (`lists.cncf.io/g/cncf-helm`) e a Developer Call semanal às quintas-feiras das 9:30 às 10:00 Pacific (`github.com/helm/community/blob/master/communication.md#meetings`), sob o código de conduta `code-of-conduct.md`.

## Por que importa
Separar `#helm-users`, `#helm-dev` e `#charts` no Slack do Kubernetes direciona dúvidas de uso cotidiano, discussões de engenharia da branch `main` (Helm v4) e questões de autoria de Charts para os públicos certos.

## Como funciona
Use `#helm-users` ou `#charts` no Kubernetes Slack para dúvidas de operação e criação de pacotes, use `#helm-dev` e a chamada de quinta-feira (9:30–10:00 Pacific) para discutir contribuições ao código do Helm e inscreva-se na lista `cncf-helm` para comunicados oficiais.

## Exemplo
Os detalhes de acesso à chamada semanal de desenvolvedores ficam centralizados no repositório `helm/community` (`communication.md#meetings`).

## Limites e trade-offs
Toda participação nos canais do Slack, na lista de e-mail e nas reuniões é regida pelo `code-of-conduct.md` linkado no final do README.

Conferi a seção Community, discussion, contribution, and support no README oficial de `helm/helm`.
