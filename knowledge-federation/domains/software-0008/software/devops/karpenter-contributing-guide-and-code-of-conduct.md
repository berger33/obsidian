# Guia de contribuição, issues para iniciantes e Código de Conduta do Kubernetes

## Em uma frase
O final da seção de comunidade do README aponta para o rastreador de issues (destacando as labels `good-first-issue` e `help-wanted`), o guia `CONTRIBUTING.md`, a página da comunidade do Kubernetes (`kubernetes.io/community`) e o **Kubernetes Code of Conduct** (`code-of-conduct.md`), além da licença Apache 2.0 do projeto.

## Por que importa
Como o núcleo do Karpenter faz parte da organização oficial `kubernetes-sigs`, todo o fluxo de contribuição, CLA e conduta segue os padrões da comunidade Kubernetes.

## Como funciona
Leia `CONTRIBUTING.md` e procure issues marcadas com `good-first-issue` ou `help-wanted` ao iniciar contribuições técnicas para o ecossistema Karpenter.

## Exemplo
Um novo contribuidor seleciona uma issue com a label `good-first-issue` e discute a abordagem com os mantenedores antes de abrir o pull request.

## Limites e trade-offs
Certifique-se de ter o CLA da Linux Foundation / Kubernetes assinado antes de submeter pull requests aos repositórios sob `kubernetes-sigs`.

## Como verificar
Conferi os badges de topo e a subseção Code of conduct no README oficial de kubernetes-sigs/karpenter.
