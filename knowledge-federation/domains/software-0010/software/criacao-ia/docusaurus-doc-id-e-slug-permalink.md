# Docusaurus: separar identidade do documento de sua URL pública com slug explícito

## Em uma frase
O ID padrão de um documento deriva do caminho relativo do arquivo, enquanto `slug` pode fixar a URL pública independente desse caminho.

## Por que importa
Mover ou renomear Markdown altera o ID e URL inferidos, o que pode quebrar links externos mesmo quando o conteúdo permanece igual.

## Como funciona
Defina `slug` explícito no front matter para páginas com permalinks importantes e use `id` como identificador interno para sidebars manuais, hooks e referências da API.

## Exemplo
Um arquivo `guides/hello.md` recebe `slug: /bonjour`; renomear ou reorganizar o arquivo preserva o permalink `/docs/bonjour` enquanto IDs são ajustados nas referências internas.

## Limites e trade-offs
O slug é combinado com `routeBasePath` do plugin; convenções de `index`, `README` e nome de pasta também afetam a URL padrão.

## Como verificar
Gere o site e confira URL final, links internos e IDs após renomear um arquivo, incluindo configuração que altere `routeBasePath`.
