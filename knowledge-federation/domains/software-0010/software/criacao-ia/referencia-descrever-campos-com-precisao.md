# Referência: descrever campos com precisão

## Em uma frase

Referência técnica funciona como consulta estável para parâmetros, formatos e contratos expostos por uma ferramenta.

## Por que importa

Descrições precisas evitam interpretação divergente entre documentação, código e conteúdo criado pela equipe.

## Como funciona

Agrupe itens por recurso, declare tipos, valores permitidos, defaults e efeito observável conforme fonte oficial.

## Exemplo

Uma referência de configuração lista chave, enum, valor padrão e contexto em que o parâmetro é lido.

## Limites e trade-offs

Copiar API de uma versão antiga torna a tabela perigosa; defaults podem variar ou depender de plugin.

## Como verificar

Compare amostras da documentação com a versão instalada e teste valores-limite descritos na referência.
