# Diátaxis Tutoriais: conduzir novos usuários ao primeiro resultado palpável

## Em uma frase
Tutoriais no modelo Diátaxis são lições práticas que guiam o aprendiz passo a passo até a conclusão bem-sucedida de um projeto inicial.

## Por que importa
Tutoriais que se perdem em explicações teóricas densas desmotivam o desenvolvedor antes que ele consiga rodar o primeiro exemplo.

## Como funciona
Conduza o leitor através de uma sequência linear e reproduzível de ações sem alternativas ou bifurcações, garantindo que ao final do tutorial ele tenha uma aplicação ou mecânica funcionando na tela.

## Exemplo
```markdown
# Tutorial: Criando seu Primeiro Inimigo com IA no Godot 4

1. Crie uma nova cena com o no CharacterBody3D.
2. Anexe o script basic_enemy.gd fornecido abaixo.
3. Pressione F6 para rodar a cena e observe o inimigo seguir o cursor.
```

## Limites e trade-offs
Incluir opções alternativas ("você pode usar X ou se preferir Y") distrai o aprendiz e aumenta a probabilidade de erros durante o aprendizado.

## Como verificar
Execute o tutorial do zero em um ambiente limpo para confirmar que nenhuma etapa ou dependência oculta foi omitida.
