# Onde pedir ajuda: Discussions, Discord e Stack Overflow

## Em uma frase
O bloco "Questions, Problems, Help needed?" nomeia os três canais oficiais de suporte da comunidade: GitHub Discussions da organização cucumber (orgs/cucumber/discussions), o Discord do Cucumber (linkado pela seção get-in-touch do site oficial) e perguntas no Stack Overflow com a tag cucumber-jvm.

## Por que importa
Um framework quase totalmente voluntário vive da velocidade de resposta da comunidade; a separação entre Discussion (dúvidas/design), Discord (tempo real) e Stack Overflow (busca futura) é o triage que o projeto adota para não perder conhecimento.

## Como funciona
Dúvidas conceituais e de design vão para as Discussions ou o Discord; erros com reproduzir e log vão para o Stack Overflow com a tag do projeto (buscável por todos) e viram issue no tracker quando há defeito confirmado — os três destinos estão linkados no README.

## Exemplo
Colar o trecho do erro com a versão exata do framework no formato de pergunta do Stack Overflow tagged aumenta a chance de resposta voluntária; "não funciona" sem versão e sem stack não entra no radar.

## Limites e trade-offs
O README lista os canais como destinos de pergunta; nenhum deles é suporte contratual, e a ausência de resposta não indica abandono do projeto.

## Como verificar
As três linhas da seção de perguntas do README oficial definem a nota.
