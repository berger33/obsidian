# Contribuir: do CONTRIBUTING.rst aos rótulos de issue

## Em uma frase
O README orienta quem quer contribuir: começar pelo arquivo CONTRIBUTING.rst do repositório e, na falta de um tema próprio, procurar issues com os rótulos "good first issue" e "help wanted" no tracker do GitHub; lembra ainda que há "muitas outras ferramentas e bibliotecas" no ecossistema amplo onde contribuir.

## Por que importa
A governança aberta do framework significa que correções de sintaxe ou documentação não dependem de vendor: o README fornece a trilha de entrada, e os rótulos de boas-vindas existem exatamente para reduzir atrito de primeira contribuição.

## Como funciona
Antes de abrir pull request para o núcleo, leia CONTRIBUTING.rst, escolha uma issue com selo adequado e declare na PR; contribuições de biblioteca seguem o processo do repositório próprio de cada projeto do ecossistema.

## Exemplo
Um fix de documentação da linguagem de teste: filtre issues do repositório robotframework/robotframework por "good first issue", cite a issue na PR e aponte para o CONTRIBUTING.rst como processo seguido.

## Limites e trade-offs
O README apenas endereça o caminho; critérios de aceite, CI e review do projeto vivem no CONTRIBUTING.rst e no tracker, não na nota.

## Como verificar
Abrir o CONTRIBUTING.rst linkado e os dois filtros de issue indicados no README confirma a trilha descrita.
