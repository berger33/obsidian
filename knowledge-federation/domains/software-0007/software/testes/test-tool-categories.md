# Categorias de ferramentas apoiam diferentes atividades de teste

## Em uma frase
Ferramentas de teste apoiam atividades diversas: gestão, análise estática, desenho, execução, cobertura, testes não funcionais, colaboração e entrega.

## Por que importa
Reduzir “ferramentas de teste” a frameworks de automação ignora apoio a requisitos, defeitos, configuração, comunicação e ambientes. Classificar por tarefa ajuda a identificar lacunas sem comprar um produto por moda.

## Como funciona
O CTFL apresenta categorias como test management; ferramentas para teste estático; desenho e implementação; execução e cobertura; testes não funcionais; DevOps; colaboração; e apoio à escalabilidade e padronização de implantação. A lista é não exaustiva: até uma planilha pode ser ferramenta quando apoia uma atividade de teste.

## Exemplo
Um projeto pode combinar issue tracker para defeitos, linter para análise estática, framework para execução, ferramenta de carga para performance e containerização para padronizar ambiente.

## Limites e trade-offs
Categorias podem se sobrepor e um produto pode cobrir várias tarefas. A presença de uma ferramenta não garante qualidade, rastreabilidade ou uso consistente.

## Como verificar
Para cada atividade, identifique problema, dado de entrada, resultado esperado e responsabilidades; confirme se a ferramenta escolhida realmente reduz esforço ou melhora evidência.
