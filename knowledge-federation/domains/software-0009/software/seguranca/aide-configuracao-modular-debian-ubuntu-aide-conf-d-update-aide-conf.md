# Arquitetura Modular no Debian/Ubuntu (**`/etc/aide/aide.conf.d/`**): **`update-aide.conf`**, **`aideinit`** e Integração com Pacotes `.deb`

## Em uma frase
Nas distribuições da família **Debian e Ubuntu**, editar diretamente um único arquivo monolítico `/etc/aide/aide.conf` não é o padrão recomendado: o pacote Debian do AIDE implementa uma arquitetura modular inteligente em **`/etc/aide/aide.conf.d/`** onde cada pacote instalado (como `openssh-server`, `apache2`, `postgresql`, `systemd`, `sudo`) pode fornecer seu próprio fragmento de regras de integridade!

## Por que importa
Sempre que você executa o utilitário **`update-aide.conf`** (ou **`aideinit`**), ele concatena `/etc/aide/aide.conf` com todos os fragmentos válidos em `/etc/aide/aide.conf.d/` (ex.: `31_aide_sshd`, `31_aide_sudo`, `70_aide_etc`, `99_aide_root`) para gerar o arquivo de configuração compilado final em **`/var/lib/aide/aide.conf.autogenerated`**!

## Como funciona
Isso significa que, para adicionar suas próprias regras corporativas ou exclusões em servidores Ubuntu/Debian sem perder suas alterações em atualizações do `apt`, basta criar um arquivo numerado em **`/etc/aide/aide.conf.d/50_aide_custom_corp`** e rodar `sudo update-aide.conf`!

## Exemplo
```bash
# Criar uma regra modular customizada em /etc/aide/aide.conf.d/, compilar a configuracao com update-aide.conf e validar a sintaxe
sudo tee /etc/aide/aide.conf.d/50_aide_custom_corp >/dev/null <<'EOF'
/opt/aplicacao-critica/bin FIPSR
!/opt/aplicacao-critica/tmp
EOF
sudo update-aide.conf
sudo aide -c /var/lib/aide/aide.conf.autogenerated --config-check
```

## Limites e trade-offs
Ao rodar o comando `aide` manualmente no Debian/Ubuntu, lembre-se sempre de passar **`-c /var/lib/aide/aide.conf.autogenerated`** (ou usar o wrapper **`aide.wrapper`**), que garante o carregamento da configuração completa gerada pelo `update-aide.conf` e adquire um lock exclusivo para evitar execuções concorrentes.

## Como verificar
Verifique os timers do systemd (`systemctl status dailyaidecheck.timer` no Ubuntu/Debian) para auditar a execução diária automatizada do AIDE.
